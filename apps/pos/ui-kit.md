## Rules
- Reference / library model: keep this app's own architecture (Riverpod, Dio, freezed). Never import the kit's Bloc/Cubit or any `package:devkit/...`.
- Borrow and adapt — take only what a screen needs; kits carry duplicated and unnecessary widgets.
- Pull across only the assets/packages a ported widget actually uses.
- Keep this app's `lib/` clean and deduplicated; treat the reference dir as read-only (re-vendor to update).
